# Sri Lankan Gems Info 💎

Welcome to the **Sri Lankan Gems Info** project! This web platform serves as an educational hub dedicated to showcasing the natural beauty and geological significance of gemstones found in Sri Lanka.

## 🌟 Key Features
- **Interactive Gem Gallery:** Explore a wide range of gemstones with a filtered viewing experience.
- **Detailed Gem Properties:** Learn about the hardness (Mohs scale), refractive index, and unique characteristics of each stone.
- **Geological Insights:** Understand the formation and geographical origins of Sri Lankan gems.
- **Industry Overview:** Gain knowledge about the sustainable and ethical practices within the local gem industry.
- **Modern UI:** A clean, dark-themed responsive interface designed for optimal readability.

## 🛠️ Technologies Used
- **HTML5:** Semantic structure.
- **CSS3:** Custom styling, grid layouts, and responsive design.
- **JavaScript:** Interactive modals, filtering logic, and image handling.
- **Font Awesome:** Scalable vector icons.
- **Google Fonts:** Poppins typography.
